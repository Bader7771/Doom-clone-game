# Weapon art

`rivet12_sheet_source.png` is an original six-frame sprite sheet generated for VOIDLOCK. It depicts the fictional RIVET-12 industrial scattergun and is not derived from a commercial game asset.

The runtime samples each frame directly into the 640×360 software framebuffer with nearest-neighbor scaling. Frame order is idle, anticipation, fire, recoil, recovery, and return.
